## 1. Milestone Overview

Milestone V1.6 integrates **Visiq AI Analytics Assistant**, an executive conversational data analyst that answers complex business questions exclusively over the `mart` and `dq` schemas using strictly predefined, deterministic tools.

### Core Architectural Guarantees
1. **Zero Free-Form SQL:** No LLM-generated arbitrary SQL against operational or analytical databases.
2. **Deterministic Computation:** Numbers are calculated via conformed SQL aggregations on `mart`. The LLM receives computed numbers and generates executive narratives with **0% numerical hallucination**.
3. **Data Privacy (RA 10173):** Personal customer contacts (phone numbers, personal emails) are omitted from analytical tables and protected by input safety filters.
4. **Data Freshness & DQ Visibility:** Every response reports ETL run freshness (`etl.runs`) and active data quality warnings (`dq.test_results`).
5. **RBAC Gating:** All operations require `analytics:use` permission (`admin`, `management`, `finance`). Every action is synchronously audited (`action = 'ai_tool_call'`).
6. **Workspace Sessions & Widgets:** Interactive workspace sessions with 4 starter questions, responsive Plotly.js charts (light/dark responsive), and persistent KPI widget pinning.
