# Milestone V1.7 Release Notes: AI-Assisted ERP

**Release Date:** October 12, 2026  
**Status:** Completed  
**Branch:** `feat/v1.7-ai-assisted-erp`

---

## 1. Executive Summary

Milestone V1.7 introduces operational AI assistance natively into the ERP/CRM platform. Operating as an intelligent copilot, the assistant runs strictly **as the requesting user** through the existing service layer (`CRMService`, `SalesService`), respecting object-level RBAC scopes (`own`, `department`, `all`).

Crucially, the system features a robust **prompt-injection defense** isolating untrusted record text from model instructions, and strictly guarantees **human-in-the-loop confirmation** by never mutating any database record automatically. All mutation recommendations are returned as structured `DraftAction` items requiring explicit user approval.

---

## 2. Key Capabilities Implemented

1. **Deterministic Operational Tools**:
   - `get_lead`, `get_customer`, `get_opportunity`, `list_activities`, `get_invoice`, and `search_records`.
   - All tools wrap existing domain service layer methods and execute under the caller's `ScopeContext`.
2. **Prompt-Injection Defense**:
   - Encapsulation of untrusted record text within secure delimiters (`<<<UNTRUSTED_RECORD_DATA>>>...<<</UNTRUSTED_RECORD_DATA>>>`).
   - Automated regex detection for adversarial prompt injection patterns (`ignore previous instructions`, `system override`, `list all customers`).
   - Quarantining of untrusted inputs prevents unauthorized tool execution.
3. **Record Summarization & Guidance**:
   - Contextual executive summaries for Leads and Customers including activity feeds.
   - Stage-specific next steps for Opportunities with tailored `DraftAction` payloads.
   - Contextual follow-up email drafting for leads, customers, and opportunities.
4. **Financial Balance Explanations**:
   - Clear decomposition of invoice balances: grand total, credits applied, payment allocations, and overdue status.
5. **Scoped Cross-Entity Search**:
   - Natural-language search across Leads, Customers, Deals, and Invoices respecting user permissions.
6. **Audit Trail Logging**:
   - Every AI tool invocation records an append-only entry in `audit_log` with `action = 'ai_tool_call'`.
7. **FastAPI Endpoints & RBAC**:
   - Router mounted at `/api/v1/assistant/*` guarded by `require("assistant:use")`.
